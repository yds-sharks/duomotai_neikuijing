# 权重模块标签规范 V2.1

## 1. 任务目标
模型输出两个彼此独立的分类：

1. `density_level`：文本本身是否包含“可用于缩小检索范围的小范围锚点”，分为 `L0-L4`
2. `routing_preference`：问题更倾向走文本通道、均衡通道还是图片通道，分为 `R1-R3`

这两个标签必须独立标注，严禁互相映射。

兼容性说明：
- 旧代码或旧文件里如果仍出现 `image_dependency` 字段，V2.2 开始应理解为 `routing_preference` 的兼容别名
- 新语义不再强调“图片依赖程度评级”，而强调“通道倾向”

## 2. 什么叫“有效检索锚点”
这里的“锚点”不是泛泛的医学词，而是能显著缩小检索空间的小范围限定词。

### 2.1 计入有效锚点的内容
- 具体部位：`胃窦` `回盲部` `食管下段` `胃体小弯`
- 具体病变：`囊肿` `糜烂` `息肉` `结节样隆起` `静脉曲张`
- 病理或类别名词：`腺癌` `Barrett食管` `溃疡性结肠炎`
- 关键属性：`散在` `多发` `白苔样` `0-IIc` `SM2`
- 专业术语：`NBI` `IPCL` `Mayo评分` `BBPS`

### 2.2 不计入有效锚点的内容
- 泛场景词：`内镜` `内窥镜` `图片` `图像`
- 泛医学词：`病变` `异常` `问题` `情况`
- 泛动作词：`显示` `看到` `判断`
- 数据集公共前提：如果样本全是内镜图像，那么 `内镜` 不具备检索缩小作用

一句话说：
只有能把搜索范围从“大类医学文本”缩到“小范围候选集”的词，才算有效锚点。

## 3. density_level 定义

### L0
- 没有有效检索锚点
- 只有指代、泛词、场景词或空泛问法

例子：
- `这张图片显示什么病变？`
- `这个有问题吗？`
- `这是什么情况？`

### L1
- 有极弱锚点，但仍不足以形成稳定检索
- 常见是只有一个大范围类词，或只给出非常粗的方向

例子：
- `小肠图片有病变吗？`
- `胃部有异常吗？`

说明：
- `小肠` 算锚点，但 `病变` 不算
- 这种文本仍然只能粗缩范围

### L2
- 至少包含 1 个明确的小范围有效锚点
- 但总体约束仍然偏宽

例子：
- `小肠囊肿`
- `胃窦糜烂`
- `食管白苔样改变`

### L3
- 含有 2 个以上彼此配合的小范围锚点
- 文本本身已具备较明确检索方向

例子：
- `小肠囊肿有什么症状`
- `胃窦散在糜烂考虑什么病`
- `食管下段白苔样附着是什么`

### L4
- 多个高价值限定词联合出现
- 文本本身已经能明显缩小检索空间

例子：
- `胃窦小弯侧散在糜烂伴结节样隆起更考虑什么病变`
- `食管下段0-IIc病变伴白苔样改变提示什么`

## 4. routing_preference 定义

### R1 文本通道倾向
- 文本本身信息足够多，明显更适合文本检索通道
- 即使完全不给图片，也能通过文本完成大部分理解或回答方向判断

例子：
- `小肠囊肿有什么症状`
- `胃窦散在糜烂考虑什么病`

### R2 双通道均衡
- 文本和图片都提供了重要信息
- 没有明显倾向只走文本或只走图片
- 常见是文本已经有明确锚点，但最终仍需要图片落地判定

例子：
- `这张小肠图片显示有囊肿和病变吗`
- `图中的胃窦糜烂更像什么病`

### R3 图片通道倾向
- 图片信息明显更多
- 单靠文本很难完成任务，问题天然更适合图片通道

例子：
- `这张图片显示哪个部位`
- `图里是什么病变`
- `箭头所示是什么`

## 5. 标注优先级
1. 先判断这句话更应该走哪个通道，得到 `R`
2. 再判断文本里有没有小范围有效锚点，得到 `L`
3. 不允许因为 `L` 高就自动判低 `R`
4. 不允许因为 `R` 高就自动判低 `L`

## 6. 构造原则
- 旧数据只能用来提供“小范围事实锚点”，不能再按锚点个数机械映射到等级
- 需要显式构造：
  - `同样锚点，不同通道倾向`
  - `同样通道倾向，不同锚点密度`
  - `同义改写 / 语序扰动` 保持标签不变
  - `只增减一个小范围锚点` 触发等级变化
