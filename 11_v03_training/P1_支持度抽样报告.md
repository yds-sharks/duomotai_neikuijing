## 1. 结论：按原计划进入 P2，同书排除无需放宽

**77/100 题存在支持文段**（至少一条 u_i > τ+=0.2），且关键的是——排除题图与同书后，支持文段全部来自**别的书**，说明语料库跨书覆盖是真实的。

| 指标 | 数值 |
|---|---|
| 有支持题占比（全体） | **77%**（77/100） |
| 按题型 | 器官识别 **86%**（43/50）；内容类型 68%（34/50） |
| **真正需要检索的题**（空证据 base_logp < −0.5，73 道）中有支持 | **97.3%**（71/73） |
| max_u（题内最优文段的 utility） | 均值 0.89 / 中位 0.82 |
| 存在有害文段（u_i < τ−=−0.2）的题 | 65/100；有支持题中正负并存 54/77 |
| 空证据基线正确率 | 41%（检索提升空间大） |

## 2. 关键发现：无支持的 23 题基本是"模型本来就会"的题

- 23 道无支持题中 **21 道（91%）空证据就能答对**（base_correct=True），其 base_logp 中位仅 −0.13；
- 有支持题的 base_logp 中位为 −1.69——**支持文段恰好集中在模型没把握的题上**，与训练需求完全匹配；
- 真正的语料盲区只有 2 道（base<−0.5 且无支持），占比 2%，P2 出题时过滤即可。

**对 P2 的直接指导**：出题应优先从 `base_logp_gold` 低的源样本构造（模型不会、检索有支持），"模型本来就会"的题（如部分内容类型元题）训练价值低，少出或不出。

## 3. 正负样本素材充足（RAG 内部 agent 的学习信号）

- 65/100 题的候选池中存在有害文段（加上会拉低答对把握的干扰描述）；
- 54/77 有支持题**同时**含正类与有害文段——agent 必须学会区分"相关且支持"与"相关但误导"，这正是 keep/drop 能力的核心训练素材；
- 候选池平均 19.8 条/题（两路 oracle query 合并去重后），逐文段 utility 标注的密度足够。

## 4. 方法

1. 与 P0 同批 100 题（train.jsonl 分层抽样，seed=0），`LeaveOneOutRetriever`（留一 + 同书排除，文本 8 / 图像 4）
2. 每题两种 oracle query 各检索一轮，候选合并去重：
   - `oracle_answer`：题干 + gold 答案文本
   - `oracle_context`：源样本 `pdf_context_text` 前 200 字
3. 冻结 Qwen3.5-4B 逐文段打 answer-utility（logprob 版）：
   `u_i = logP(gold|题,图,[p_i]) − logP(gold|题,图,∅)`，一次前向取选项字母位置 logsumexp → log_softmax → gold 位置（复用 v0.5 gen_scorer 方案；prompt 用 harness 同款 `render_generator_prompt`，与后续训练 reward 格式一致；证据只喂 text、截 400 字，与训练时 M+ 为文段一致）
4. 注：原 `verify_kb_support.py` 已被清理不在磁盘，公式按 `09_legacy_deprecated/.../gen_scorer.py` 的 `_option_logits` 对齐重建；旧 reward bank 基于 Qwen3-VL-8B，本次起以 4B 数值为准（与 v0.3 统一基座决策一致）
