# 核心代码梳理

这个目录现在分开记录两套不同模块，避免后续把“检索”和“权重分配”混在一起。

## 1. 多模态检索模块

真实检索配置与历史说明整理在这里：

- [多模态检索模块.md](/mnt/data_1/yds/多模态/核心代码梳理/多模态检索模块.md)

这一份对应你确认过的真实检索说明来源：

- [`retrieval/多模态/READ.ME`](/mnt/data_1/yds/多模态/retrieval/多模态/READ.ME)

核心含义：

- 输入可以是文本或图片
- 检索的是双库：
  - `text_vector_index`
  - `image_vector_index`
- 主向量库文件是：
  - `/mnt/data_1/yds/多模态/data_house/milvus/multimodal_vector_indexes.db`
- 之前构建文本向量库的代码链也已经补充进去了
- 当前已确认：现有构建脚本默认是“全量重建文本库”，不是直接增量追加
- 已新增一个安全的文本追加脚本，默认先校验 JSONL，再显式 `--append` 入库
- 已新增一个图文统一的 PPR rerank 脚本，默认使用 `dense_top20 + top20_image_hits`

## 2. 权重分配模块

权重分配模块整理在这里：

- [权重分配模块.md](/mnt/data_1/yds/多模态/核心代码梳理/权重分配模块.md)

这份对应的核心脚本是：

- [`权重模块/multimodal_weight_service.py`](/mnt/data_1/yds/多模态/权重模块/multimodal_weight_service.py)

核心含义：

- 这是一个权重/标签分析模块
- 不是向量检索模块
- 当前实现主要做文本侧分析
- 输出的是标签和置信度，不是检索结果

## 3. 当前区分结论

为了后面不混淆，可以先固定这样理解：

- `retrieval/多模态/*`
  - 负责向量库构建与检索
  - 关注文本库、图片库、Milvus、embedding、召回结果

- `权重模块/*`
  - 负责输入内容分析、打标签、做权重判断
  - 关注语义密度、图片依赖、分类概率、排序分数
