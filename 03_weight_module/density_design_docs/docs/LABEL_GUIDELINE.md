# 文本语义密度标注规范（V1.1）

## 1. 标注总原则
- `density_level` 反映“文本可独立检索能力”，不是句长等级。
- `image_dependency` 必须独立判断，不允许从 `density_level` 直接映射。
- 优先看关键槽位：`anatomy / lesion / attribute / distribution / severity`。

## 2. 关键术语
- 强约束槽位：`anatomy`、`lesion`
- 弱约束槽位：`attribute`、`distribution`、`severity`、`context`
- 指代表达：如“这张图/这里/箭头所示/该处”
- 泛化表达：如“有问题吗/正常吗/帮我看看”

## 3. density_level 定义
### L0（极低）
判定：
- 基本无稳定医学实体，无法形成有效检索条件。
- 常见为泛问或纯指代。

典型：
- “帮我看看”
- “这是什么”
- “有没有问题”

### L1（低）
判定：
- 有非常弱的约束，但仍高度依赖图像上下文。
- 可能出现部位猜测或是非问句，但缺病变核心信息。

典型：
- “这是胃吗”
- “这个部位正常吗”
- “这张图对应哪个部位”

### L2（中）
判定：
- 至少 1 个稳定关键约束（强约束 1 个，或弱约束 2 个）。
- 可做粗检索，但结果集合仍较宽。

典型：
- “胃窦糜烂”
- “食管白苔”
- “幽门水肿”

### L3（中高）
判定：
- 2-3 个稳定约束，具备较好独立检索性。
- 常见组合：`anatomy + lesion`，或 `anatomy + lesion + attribute`

典型：
- “胃窦黏膜发红伴糜烂”
- “食管下段白苔样附着”

### L4（高）
判定：
- 多槽位联合约束（通常 >=4 槽位），能显著缩小检索空间。
- 含部位、病变、形态/分布/严重度等完整描述。

典型：
- “胃窦小弯侧黏膜充血发红伴散在糜烂更像什么病变”

## 4. image_dependency 定义
### 0（低依赖）
- 不看图也可做有效检索。
- 关键实体与关系完整。

### 1（中依赖）
- 文本可检索，但缺少部分关键定位或严重度信息。
- 看图可明显提升理解与判定。

### 2（高依赖）
- 核心语义依赖图像指代，文本本身难以检索。
- 常见“这里/该处/箭头所示”且无稳定医学实体。

## 5. 冲突判定优先级
1. 是否有新事实或事实冲突（若有，样本直接不合格）
2. 是否能独立检索（先判 dependency）
3. 再判 density_level

## 6. 标注一致性规则
- 同一 `semantic_core_hash` 下，主链必须 `L0 < L1 < L2 < L3 < L4`。
- level 相邻项应有明确信息差异，不能只做语气改写。
- 如果 `Lx` 与 `Ly` 信息量无实质差异，整条链标为不通过。
